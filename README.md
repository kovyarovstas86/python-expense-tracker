\# Python Expense Tracker



\## 1. Название проекта



\*\*Python Expense Tracker\*\* — программа для учёта личных расходов.



\## 2. Описание проекта



Python Expense Tracker — консольное приложение, разработанное на языке Python. Программа предназначена для добавления, хранения и анализа личных расходов. Она помогает пользователю контролировать затраты и получать информацию о своих финансовых операциях.



\## 3. Возможности программы



Программа поддерживает следующие функции:



\- Добавление новых расходов.

\- Просмотр списка расходов.

\- Расчёт общей суммы расходов.

\- Расчёт среднего значения расходов.

\- Определение самой большой траты.

\- Поиск расходов по категориям.

\- Проверка корректности введённых данных.

\- Подсчёт количества расходов.

\- Операционная система Windows, Linux или macOS.



\## 7. Установка проекта



1\. Склонировать репозиторий:



```bash

git clone https://github.com/kovyarovstas86/python-expense-tracker.git

```



2\. Перейти в папку проекта:



```bash

cd python-expense-tracker

```



3\. Создать виртуальное окружение:



```bash

python -m venv venv

```



4\. Активировать виртуальное окружение в Windows:



```bash

venv\\Scripts\\activate

```



5\. Установить необходимые зависимости:



```bash

pip install -r requirements.txt

```



\## 8. Запуск программы



Для запуска приложения выполните команду:



```bash

python src/main.py

```
